# Nand2Tetris - Computer Systems Project

This repository contains my work and learnings from the **Nand2Tetris** course, which is a hands-on journey through building a modern computer system from the ground up.
**Nand2Tetris** (officially known as *The Elements of Computing Systems*) is a course that teaches how to build a complete computer, starting with NAND gates and progressing to a full operating system and high-level programming language.

### Nand2Tetris means:

NAND ➔ The most basic logic gate (NAND = NOT AND).
With just NAND gates, you can build every other logic gate (for instance, AND, OR, NOT, XOR).

Tetris ➔ A real, working computer game.
Meaning I have built a full computer that’s capable of running games like Tetris!

So **Nand2Tetris** =
Starting from just the NAND gate 👉 building all the way up to a computer that can run Tetris (and more!)

I learned and implemented:
- Logic gates and combinational chips (using Hardware Description Language - HDL)
- A 16-bit Hack CPU and memory system
- Assembler for translating Hack Assembly code
- Virtual machine and stack-based computation
- Basic operating system and compiler for a high-level language

---

## Skills and Concepts Practiced

- **Digital logic design** (Boolean algebra, flip-flops, sequential circuits)
- **Computer architecture** (CPU, ALU, registers, RAM, program counter)
- **Assembler programming** (converting assembly language to machine code)
- **Virtual Machine (VM) implementation** (stack arithmetic, function calling)
- **Compiler construction** (tokenizer, parser, code generator)
- **Operating system basics** (input/output handling, memory management)

---

## Tools Used

- **Hardware Simulator** (provided by Nand2Tetris course)
- **Assembler and CPU Emulator** (for testing programs)
- **Jack Compiler** (self-built and tested)
- **VM Emulator** (for stack machine simulation)
